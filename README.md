# Route Engine

A route generation engine for office cab allocation.

## Goals

- Generate optimal cab routes
- Allocate employees to cabs
- Minimize travel distance/time
- Provide route and ETA information

## Tech stack

- Python
- OR-Tools
- FastAPI
- Pydantic
- OpenStreetMap
- OSRM

## Startup
source .venv/bin/activate

## Ending
deactivate
